# 🧪 راهنمای تست سریع ربات

## ✅ ربات با موفقیت اجرا شد!

---

## 📋 چک‌لیست تست:

### 1. منوی اصلی جدید
- [ ] دکمه "🤖 ساخت ربات" در سطر اول (تک‌سطری) است
- [ ] دکمه "🛒 خرید اشتراک" حذف شده است
- [ ] دکمه "📋 قوانین" به آخر منتقل شده

### 2. تست دکمه "🤖 ساخت ربات"
- [ ] روی دکمه کلیک کنید
- [ ] 6 نوع ربات نمایش داده می‌شود
- [ ] دکمه‌ها به صورت Inline (شیشه‌ای) هستند

### 3. تست انتخاب نوع ربات
- [ ] روی یک نوع کلیک کنید (مثلاً "🛒 ربات فروشگاهی")
- [ ] پیام تایید با نام ربات نمایش داده می‌شود
- [ ] دکمه "✅ ادامه ساخت ربات" وجود دارد

### 4. تست دریافت توکن
- [ ] روی "✅ ادامه ساخت ربات" کلیک کنید
- [ ] راهنمای 5 مرحله‌ای BotFather نمایش داده می‌شود
- [ ] ربات منتظر دریافت توکن است

### 5. تست توکن نامعتبر
ارسال کنید: `123456789`
- [ ] پیام خطا نمایش داده می‌شود
- [ ] ربات هنوز منتظر توکن صحیح است

### 6. تست توکن معتبر
ارسال کنید: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz1234567890`
- [ ] پیام "✅ توکن با موفقیت دریافت شد!" نمایش داده می‌شود
- [ ] نوع ربات نمایش داده می‌شود
- [ ] دکمه‌های "🤖 مدیریت ربات‌ها" و "🏠 منوی اصلی" وجود دارند

### 7. تست لیست ربات‌ها
- [ ] به منوی اصلی برگردید
- [ ] روی "🤖 مدیریت ربات‌ها" کلیک کنید
- [ ] روی "📋 ربات‌های من" کلیک کنید
- [ ] ربات ساخته شده در لیست نمایش داده می‌شود

---

## 🔥 مثال‌های توکن برای تست:

### ❌ توکن‌های نامعتبر:
```
123456789                    → خطا: بدون :
123:456:ABC                  → خطا: بیش از 2 بخش
abc:ABCdefGHI                → خطا: بخش اول عدد نیست
123456789:ABC                → خطا: کوتاه (کمتر از 30 کاراکتر)
```

### ✅ توکن معتبر:
```
123456789:ABCdefGHIjklMNOpqrsTUVwxyz1234567890
```

## 🎯 جریان کامل:

```
1. /start
    ↓
2. کلیک: 🤖 ساخت ربات
    ↓
3. انتخاب: 🛒 ربات فروشگاهی
    ↓
4. کلیک: ✅ ادامه ساخت ربات
    ↓
5. ارسال توکن: 123456789:ABC... (معتبر)
    ↓
6. پیام موفقیت ✅
    ↓
7. منوی اصلی → 🤖 مدیریت ربات‌ها → 📋 ربات‌های من
    ↓
8. مشاهده ربات در لیست
```

---

## 🐛 اگر مشکلی پیش آمد:

### مشکل 1: ربات پاسخ نمی‌دهد
```bash
# ربات را متوقف کنید (Ctrl+C) و دوباره اجرا کنید
python bot.py
```

### مشکل 2: توکن معتبر را قبول نمی‌کند
- مطمئن شوید فضای خالی اضافه ندارد
- مطمئن شوید طول بخش دوم حداقل 30 کاراکتر است

### مشکل 3: لیست ربات‌ها خالی است
- context.user_data موقت است
- اگر ربات را restart کنید، داده‌ها پاک می‌شوند
- برای ذخیره دائمی باید از دیتابیس استفاده کنید

---

## 📝 نکته مهم:

**توکن واقعی را از @BotFather دریافت کنید:**

1. به @BotFather بروید
2. دستور `/newbot` بزنید
3. نام ربات را وارد کنید
4. username ربات را وارد کنید (باید به bot_ ختم شود)
5. توکن دریافتی را کپی کنید
6. در ربات ما paste کنید
