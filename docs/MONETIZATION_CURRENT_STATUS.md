#### دیتابیس (database/db.py):
```sql
-- جدول کاربران
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    balance INTEGER NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL
)

-- جدول تراکنش‌ها
CREATE TABLE transactions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    amount INTEGER NOT NULL,
    type TEXT NOT NULL,           -- 'deposit' or 'withdraw'
    description TEXT NOT NULL,
    created_at DATETIME NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE
)
```

**ویژگی‌ها:**
- ✅ Index بر روی `user_id` برای جستجوی سریع
- ✅ Index بر روی `created_at` برای مرتب‌سازی
- ✅ Foreign Key برای یکپارچگی داده
- ✅ تراکنش‌ها با حذف کاربر، خودکار حذف می‌شوند

#### سرویس کیف پول (services/wallet_service.py):

## 5️⃣ فرآیند کامل ساخت ربات

### جریان فعلی:

```
کاربر → "🤖 ساخت ربات"
    ↓
انتخاب نوع ربات
    ↓
ورود توکن BotFather
    ↓
┌─ ادمین است؟
│   ├─ بله → ادامه بدون بررسی موجودی
│   └─ خیر → بررسی موجودی
│       ├─ موجودی کافی → ادامه
│       └─ موجودی ناکافی → نمایش خطا + دکمه شارژ
└─→ STOP
    ↓
اعتبارسنجی توکن با API تلگرام
    ↓
رمزنگاری توکن (Fernet)
    ↓
ذخیره در دیتابیس
    ↓
┌─ ادمین است؟
│   ├─ بله → Skip کسر هزینه
│   └─ خیر → کسر BOT_CREATION_COST از موجودی
└─→ ثبت تراکنش withdraw
    ↓
روشن کردن ربات (start_bot)
    ↓
نمایش پیام موفقیت:
  - اطلاعات ربات
  - موجودی باقیمانده (یا "رایگان برای ادمین")
  - دکمه‌های مدیریت
```
