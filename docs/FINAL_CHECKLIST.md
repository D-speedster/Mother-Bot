## 📋 قبل از اجرا

### 1. بررسی فایل `.env`
```env
# ضروری
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
FERNET_KEY=YOUR_FERNET_KEY_HERE

# اطلاعات کارت بانکی (برای شارژ کیف پول)
BANK_CARD_NUMBER=6037-9977-XXXX-XXXX
BANK_CARD_HOLDER=نام و نام خانوادگی شما
BANK_NAME=نام بانک شما

# اختیاری
BOT_CREATION_COST=50000
DATABASE_PATH=mother_bot.db
```

### 2. بررسی آیدی ادمین
در `config.py`:
```python
ADMIN_USER_IDS = [79049016]  # آیدی تلگرام خودتان
```

### 3. نصب Requirements
```bash
pip install -r requirements.txt
```

## 🧪 تست قابلیت‌ها

### تست 1: ساخت ربات (برای ادمین)
1. `/start` در ربات مادر
2. "🤖 ساخت ربات"
3. انتخاب نوع ربات
4. ورود توکن
5. **انتظار**: "ساخت ربات برای ادمین: رایگان"

### تست 2: ساخت ربات (برای کاربر عادی)
1. از یک اکانت دیگر `/start`
2. "🤖 ساخت ربات"
3. انتخاب نوع ربات
4. ورود توکن
5. **انتظار**: "موجودی کافی نیست" (اگر موجودی 0 است)

### تست 3: شارژ کیف پول
1. "💳 کیف پول من"
2. "💰 شارژ کیف پول"
3. **بررسی**: اطلاعات کارت بانکی نمایش داده می‌شود
4. "📤 ثبت فیش واریزی"
5. ورود مبلغ (مثلاً: 50000)
6. ارسال عکس یا متن
7. **انتظار**: "فیش شما با موفقیت ثبت شد"

### تست 4: تأیید فیش توسط ادمین
1. **به عنوان ادمین** باید پیام اعلان دریافت کنید
2. بررسی عکس فیش و اطلاعات
3. کلیک روی "✅ تأیید و شارژ"
4. **انتظار**: 
   - کیف پول کاربر شارژ می‌شود
   - کاربر پیام تأیید دریافت می‌کند
   - پیام ادمین آپدیت می‌شود

### تست 5: رد فیش توسط ادمین
1. ثبت یک فیش جدید
2. **به عنوان ادمین** روی "❌ رد فیش" کلیک کنید
3. **انتظار**:
   - کاربر پیام رد دریافت می‌کند
   - موجودی کاربر تغییر نمی‌کند

### تست 6: روشن/خاموش کردن ربات فرزند
1. "🤖 مدیریت ربات‌ها"
2. "📋 ربات‌های من"
3. انتخاب یک ربات
4. "⏸ توقف ربات"
5. **انتظار**: "ربات متوقف شد"
6. "▶️ فعال‌سازی ربات"
7. **انتظار**: "ربات الان آنلاین است"

### تست 7: حذف ربات
1. "🤖 مدیریت ربات‌ها"
2. "📋 ربات‌های من"
3. انتخاب یک ربات
4. "🗑 حذف ربات"
5. تأیید حذف
6. **انتظار**: "ربات با موفقیت حذف شد"

## ⚠️ خطاهای رایج و راه‌حل

### خطا: "BOT_TOKEN در .env تنظیم نشده"
**راه‌حل**: فایل `.env` ایجاد کنید و `BOT_TOKEN` را تنظیم کنید

### خطا: "FERNET_KEY در .env تنظیم نشده"
**راه‌حل**: کلید Fernet تولید کنید:
```python
from cryptography.fernet import Fernet
print(Fernet.generate_key().decode())
```

### خطا: "name 'Optional' is not defined"
**راه‌حل**: ✅ برطرف شد (import اضافه شد)

### خطا: ادمین اعلان دریافت نمی‌کند
**راه‌حل**: 
- بررسی کنید آیدی ادمین در `ADMIN_USER_IDS` باشد
- یک بار با ربات صحبت کنید تا بتواند پیام بفرستد

### خطا: "موجودی کافی نیست" برای ادمین
**راه‌حل**: مطمئن شوید آیدی شما در `ADMIN_USER_IDS` است
